# 📅 Google Calendar App

Welcome to the **Google Calendar App**! This application allows you to manage your events and tasks seamlessly. 

## 🚀 Features
- **Calendar View**: View your events in a calendar format.
- **Task Management**: Create and manage tasks easily.
- **Google Authentication**: Sign in with your Google account.
- **Responsive Design**: Works on both desktop and mobile devices.

## 📦 Installation
To get started with the project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/google-calendar-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd google-calendar-app/client
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

## ▶️ Usage
In the project directory, you can run:

### `npm start`
Runs the app in the development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`
Launches the test runner in the interactive watch mode.

### `npm run build`
Builds the app for production to the `build` folder.
